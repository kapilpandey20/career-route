1. Name of the Project

My project is called Career Route – AI Skill Gap and Career Planner.

It is a career-planning web application designed to help students and freshers understand their current skills and identify the skills they need for their desired career.

2. Was it a Solo or Group Project?

It was a solo project. I developed the project individually, including the planning, frontend, backend, database integration, resume processing, skill-matching logic, and testing.

3. Explain Your Project / Working of the Project

The main purpose of Career Route is to help students find the right learning path for their desired career.

First, the user creates an account and logs into the system. After login, the user can upload their resume in PDF format.

The system extracts the text from the resume and identifies the technical skills mentioned in it. After that, the user selects their desired career, such as Python Developer, Data Scientist, Machine Learning Engineer, or Full Stack Developer.

The system then compares the user's existing skills with the skills required for the selected career. It shows the matched skills, missing skills, and career readiness percentage.

Finally, the system provides a learning roadmap based on the skills the user needs to improve.

Easy flow to remember:

Login → Upload Resume → Extract Skills → Select Career → Skill Gap Analysis → Readiness Score → Learning Roadmap

5. Explain the Dashboard

The dashboard is the central part of my application.

After logging in, the user can access the main features from the dashboard. It provides options for uploading a resume, viewing detected skills, selecting a career, analyzing the skill gap, and viewing the learning roadmap.

After the analysis, the dashboard helps the user understand their current career readiness by displaying their matched skills, missing skills, and readiness percentage.

So, the dashboard gives the user a single place to manage and understand their career progress.

6. How is Career Route Useful to Users?

Career Route is mainly useful for students, freshers, and job seekers.

Many students are confused about what skills they should learn for a particular job role. My project helps solve this problem by analyzing their existing skills and comparing them with the requirements of their target career.

For example, if a student wants to become a Python Developer but does not have Django or SQL skills, the system can identify these as missing skills and suggest them as areas to learn.

This saves time and gives the user a more structured direction for their career preparation.

7. What Technologies Did You Use?

I used Python and Django for the backend of the project.

For the frontend, I used HTML, CSS, JavaScript, and Bootstrap.

I used SQLite for database management during development.

For resume processing, I used PyPDF to extract text from PDF resumes. For resumes where normal text extraction is difficult, I also used OCR with Tesseract and PDF-to-image processing.

I developed the project using Visual Studio Code and used Git and GitHub for version control.
